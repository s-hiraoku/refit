# refit

モデルの進化に合わせて、Claude Code のハーネスを測り、整え、作り直すためのツール。

- **台帳**：環境内のハーネス（CLAUDE.md のルール、skills、hooks、MCP、サブエージェント）をコンポーネント単位で一覧化する
- **使用率**：各コンポーネントがどれだけ使われているかを常時記録する
- **効果**：あり/なしの比較（ablation）で、どれだけ効いているかを測る
- **判定**：KEEP / CUT / ADD / REDESIGN を根拠つきで提示する
- **移行**：台帳から別エージェント向けの構成を生成する（後続フェーズ）

現在は検討段階です。詳細は [docs/spec.md](docs/spec.md) を参照してください。
